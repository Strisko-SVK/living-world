## Hypotheses, not conclusions

- Low temperature and prior NPC speech may reinforce repeated phrasing.
- Relevance scores based on NPC speech may retrieve unrelated NPC-generated facts; repeated generic fixture context may overwhelm intent.
- Nested JSON and strict response schema may affect small-model comprehension; benchmark before changing.
- Two token-count HTTP calls, possible recount, prompt evaluation, decoding, source revalidation, queue and delivery contribute to latency; no stage breakdown proves the bottleneck yet.
- Existing profile storage is deliberately narrower than the original 33-section authoring template. Preserve canonical documents, do not silently import DM-only or unselected example fields.

E using synthetic permitted context is a composer-level proxy, not a DB/Gateway integration test. Full E requires authorized real or isolated integration execution. Keep output-format confounding explicit; do not infer prompt causality from a single stochastic output. Log exact observed model, input/output tokens and elapsed time, prompt version, configuration and sample ID. Record quantization/runtime revision from operator evidence, not guesses.

Named regression RP-ABSURD-001: "I need eating forks for my miners. They will dig the tunnels with them." Evaluate intent and plausible in-character reaction without fabricated availability or completed transactions. No special-case fork logic.

Keep security and world-state boundaries unchanged. Layer A (intelligence) and short-term Layer B only; no inventory, economy, autonomous actions, long-term memory, paid models, production deployment or infrastructure changes.
