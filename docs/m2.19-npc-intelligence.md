## Architecture and decisions

Existing native Gateway -> scoped delivery history -> visibility filter -> versioned composer -> RAON -> strict speech validation -> persistent outbox remains the path. Candidate opt-in LW_NPC_DIALOGUE_VERSION=m219-v1; unset for baseline. The candidate projects allowed identity, role, summary, traits and values; retains recent 2–3 exchanges and up to three older player-topic matches, ranks permitted facts/recollections by lexical overlap and places current request last. Compact fallback keeps the latest exchange. No new disclosure rights. Dialogue remains attributed and is not world truth. No special handling of forks.

Default RAON temperature 0.1, thinking off, 4096 context, typically 192 output tokens, unchanged pending evidence. Do not raise limits or use paid fallback to conceal quality problems. Repetition counts are diagnostics, not semantic judgments. Candidate response stages, provider token-count duration, compaction use, optional actual server evaluation/decoding timings and existing delivery latency are logged without conversation content. Benchmark explicitly outputs synthetic dialogue. Hardware usage and full stage coverage still require owner-local measurement.

Record per-sample latency, input/output tokens, repetition, outcome, and optional actual runtime timings; no percentile claims for tiny samples.

## Acceptance checklist

- [ ] Same Marcus thread: absurd request to mine with eating forks; reacts to intent without inventing stock or successful transaction.
- [ ] Discuss unrelated topic, then return to it; short references and correction.
- [ ] Repeated exchanges: no repeated greeting, stale condensation fixation or fabricated facts.
- [ ] EN, SK, informal SK and no diacritics; compare Sentinel and Nemeia personality.
- [ ] Restart: history returns only in the same authorized scope; test second player and unrelated scene independently.
- [ ] Try unauthorized request, prompt injection, DM-only info and world-state mutation: no disclosure or action.
- [ ] Existing Gateway remains usable without manual IDs, webhook or campaign registration.
- [ ] Compare baseline/candidate at same model/config; log measured end-to-end and inference timings.
